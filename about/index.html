About

A fast port reference site with guides built for search intent.

Roadmap

  1. Build brand hubs and port hubs.
  2. Expand guides for compatibility searches.
  3. Add device pages with consistent specs blocks.
  4. Add affiliate blocks on guides and high intent device pages.
  5. Add sponsorship slots on hubs.
  6. Add a data feed later, behind paid access.

Page types

  • Device pages. Model, ports list, photos, common setups.
  • Brand hubs. Brand overview, top models, internal links.
  • Port hubs. What it is, limits, adapters, common issues.
  • Guides. Fix steps and buying checks.

Metrics to track

  • Search clicks per guide.
  • Affiliate click rate on guide blocks.
  • Pages per session from hub internal links.
  • Top exit pages to rewrite.
